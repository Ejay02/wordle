# Ej's Wordle Game

Welcome to my Wordle, built with Vue.js so I can play Wordle all day!

## Description

Wordle is a game where you have to guess a secret five-letter word. You have six chances to guess the word correctly. After each guess, you'll receive feedback indicating which letters are correct, incorrect, or in the wrong position.

## Features

- Randomly generated five-letter words for each new game
- Interactive keyboard for guessing letters
- Feedback on guessed letters
- Winning and losing conditions with appropriate messages
- Play again option to start a new game
- Confetti animation upon winning

## Technologies Used

- Vue.js for the frontend logic
- Random-words package for generating random words
- Canvas-confetti for the confetti animation

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/wordle-game.git
   ```

2. Install dependencies:

   ```bash
   cd wordle-game
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` to play the game.

## How to Play

- Guess the secret five-letter word by entering letters using the on-screen keyboard.
- Click the enter button to submit your guess.
- You have six chances to guess the word correctly.
- After each guess, you'll receive feedback on the correctness of your letters.
